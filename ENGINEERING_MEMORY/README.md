# Bedaim Engineering Memory

This directory is the versioned engineering notebook for experimental Bedaim work. Update it after every meaningful investigation, code change, build, or test.

## Rules
- Work only on isolated experimental branches; never modify `main` during AutoHit experiments.
- Record exact branch, commit SHA, files changed, commands/tests, and observed outcomes.
- Separate static/build evidence from in-game evidence. A successful compile, a returned `true`, particles, or an immediate hurt-time value is not proof of damage.
- Before attempting a fix, read this notebook and the latest investigation log to avoid repeating failed experiments.
- Do not claim a fix without a reproducible in-game test demonstrating target damage and no regression/lag.
